# Horloge météo rabattable HTC — version moderne

Recréation indépendante du widget HTC classique pour Android 6 à Android 16. Le projet conserve l’esprit visuel à panneaux rabattables, sans dépendance à HTC Sense et sans incorporer l’APK historique.

## Démarrage rapide sous Windows

```powershell
.\tools\start-emulator.ps1
.\tools\install-emulator.ps1
```

L’application fournit un aperçu testable, le choix d’une ville, la météo Open‑Meteo avec cache hors ligne et un bouton d’ajout du vrai widget 4×2 au lanceur.

Voir `docs\TESTING.md` pour les vérifications et `docs\ENVIRONMENT.md` pour reconstruire tout l’environnement.
