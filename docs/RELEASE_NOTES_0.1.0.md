# Retro Flip Weather Clock 0.1.0

Première version publique du portage Android moderne.

## Contenu

- trois widgets : classique 4×3, hebdomadaire 4×4 et compact 4×3 ;
- météo actuelle et prévisions sur quatre jours ;
- adresse manuelle avec validation automatique ;
- géolocalisation à la demande ;
- ouverture des alarmes Android depuis l’horloge ;
- ouverture d’une météo détaillée correspondant à l’adresse ;
- compatibilité Android 6 à Android 16.

## Installation

Téléchargez l’APK joint à cette release puis autorisez l’installation depuis votre navigateur ou gestionnaire de fichiers lorsque Android le demande.

Cette application est un projet non officiel, sans affiliation avec HTC Corporation.
