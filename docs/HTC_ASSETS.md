# Ressources visuelles HTC

Les ressources de `app/src/main/res/drawable-xxhdpi` suivantes proviennent de l’APK **HTC Weather Clock Widget 8.50.829652** authentifié par le certificat Android historique de HTC :

- `clock_weather_clock_tab_up.webp` et `clock_weather_clock_tab_down.webp` : moitiés des volets ;
- `common_panel_dark.9.png` : bandeau météo ;
- `weather_colorgraphic_xl_*.webp` : illustrations météo jour et nuit.

L’APK de référence n’est pas distribué par Git. Les empreintes reproductibles et la provenance sont conservées dans `reference/original`.

Le code applicatif, l’accès à Open‑Meteo, le stockage, la configuration et le rafraîchissement ont été réécrits. Aucun code exécutable, composant Sense ou permission propriétaire HTC n’est repris.
